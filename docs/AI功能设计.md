# 🤖 AI 功能接入设计（可选模块）

> 状态：**设计稿**（尚未实现）。系统核心功能完全离线，AI 是可选增强——不配置就永远不联网。

## 一、设计原则

1. **默认关闭**：不配置任何模型时，系统行为与现在完全一致（复盘草稿走本地规则）
2. **隐私边界清晰**：只把"你当次主动请求"的内容发给模型，绝不后台偷偷扫描你的日记
3. **密钥只存本地**：API Key 保存在 `backend/data` 的 settings 表里（该目录已被 .gitignore 屏蔽，不会随开源上传）
4. **可插拔**：本地模型和云模型用同一个适配器接口，随时切换

## 二、两种接入方式（二选一或都配）

| | 🏠 本地 Ollama（推荐） | ☁️ 云 API |
|---|---|---|
| 联网 | 完全离线 ✅ | 需联网 |
| 数据 | 不出电脑 ✅✅ | 发给服务商（选大厂可靠服务） |
| 成本 | 免费（吃本机 CPU/GPU） | 按 token 付费（很便宜） |
| 质量 | 中等（qwen2.5:7b 级别够用） | 更强（GLM / DeepSeek / GPT 等） |
| 安装 | [ollama.com](https://ollama.com) 下载 → `ollama pull qwen2.5:7b` | 注册拿 API Key 即可 |

## 三、值得 AI 化的模块（按价值排序）

### 1️⃣ 周报/月报"AI 润色"（最推荐先做）
- 现状：复盘草稿是本地规则拼的模板（数字准但没有温度）
- AI 后：把本周统计 + 日记摘要交给模型 → 生成"有人味"的复盘初稿，像懂你的朋友帮你写周记
- 接口：`POST /api/reviews/draft-ai`（设置页开启后，复盘弹窗多一个"✨ AI 润色"按钮）

### 2️⃣ 日记"今日回顾"
- 写完日记点一下 → AI 提炼三句话总结 + 情绪倾向，存进日记的 summary 字段
- 月底翻看时，30 篇日记的 AI 摘要串成一个月度速览

### 3️⃣ 知识卡片自动摘要 + 自动打标签
- 批量导入长文时 → AI 生成一句话摘要 + 建议 3 个标签（沿用现有标签体系）
- 图谱会因此长得更密更好看（标签是图谱的连线）

### 4️⃣ 图谱关联建议（进阶）
- AI 读你的卡片库 → 提示"这张『费曼学习法』和『番茄工作法』都关于学习方法，要不要加个共同标签？"

## 四、技术架构（实现时照此扩）

```
backend/app/ai.py          ← 唯一新增文件：模型适配器
  ├─ class AIProvider      ← 统一接口：chat(prompt, content) -> str
  ├─ class OllamaProvider  ← http://127.0.0.1:11434（本机 Ollama）
  └─ class CloudProvider   ← OpenAI 兼容格式（GLM/DeepSeek/通义都兼容）
                             base_url + api_key 从 settings 表读

设置页（数据中心 → 设置）新增：
  AI 模式：禁用 / 本地 Ollama / 云 API
  API 地址、Key、模型名（存 settings 表，随数据库备份）

各功能路由只加 /ai 后缀端点，前端按钮仅在"AI 模式 ≠ 禁用"时显示。
```
