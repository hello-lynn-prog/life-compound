# 🌸 人生复利系统 · 使用手册

> 一款完全离线、数据只存在你自己电脑里的可爱风个人成长工作台。
> 把 **目标计划、每日行动、日记随手记、知识积累、成长图谱、个人 IP 档案** 整合成一个循环：
> 长期方向 → 阶段目标 → 项目计划 → 每日行动 → 总结记录 → 知识与成果 → 定期复盘 → 调整计划

---

## 一、两种启动方式的区别（重要！）

| | `首次安装.bat` | `启动.bat` |
|---|---|---|
| **什么时候用** | 只在**拿到程序的第一天**运行一次 | **每天日常使用**双击它 |
| **做什么** | 检查 Python、创建独立运行环境、安装依赖、可选注册开机提醒 | 启动本地服务 + 自动打开浏览器 |
| **耗时** | 约 1-2 分钟 | 几秒钟 |

**首次安装前请确认电脑装了 Python**（到 [python.org](https://www.python.org/downloads/) 下载 3.10 以上版本，
安装时务必勾选 **"Add Python to PATH"**）。

日常启动后会出现一个黑色命令行窗口——**使用期间请不要关它**（它就是程序的"发动机"），
用完直接关掉窗口即可退出。如果双击时程序已经在运行，会直接打开页面，不会开两个。

> 放心：这个程序**不需要联网**（安装依赖那一次除外），数据不会上传到任何地方。

## 二、七个页面怎么用

### 🏠 今日（每天打开的第一站）
- **今日任务**：输入框写任务，回车或点"添加"。点圆圈打勾 🚩 可以标记重要任务，
  展开后还能关联到目标/项目（也可以完全不关联）
- **习惯打卡**：点一下就算打卡，再点一下取消
- **今天心情**：点一个表情，会自动记到今天的日记里
- **今日一句速记**：冒出来的小想法，点"存📌"进随手记便签墙

### 🎯 目标（想清楚要去哪）
- 三层结构：**长期方向**（如"成为 AI 开发者"）→ **阶段目标**（如"半年做出 Agent 产品"）→ **项目**
- 每一层自动统计下面任务的完成百分比
- 今日页的任务关联到目标后，进度会自动涨

### 📔 日记（想写就写，不用关联任何任务）
- 支持 Markdown 格式（`## 标题`、`- 列表`、`**加粗**`），可随时预览
- 每篇可以选心情和天气、打标签
- 右侧**随手记便签墙**：碎片想法先钉在这，哪天想展开写了点"✍️ 转日记"

### 💡 知识（把学到的变成卡片）
- 每张卡片：标题 + 内容 + 分类 + 标签 + 出处
- 支持全文搜索、按分类/标签筛选
- 复习过的卡片点"🔁 再复习一遍"，会记录复习次数

### 📈 图谱（把努力画成看得见的风景）
- 年度热力图：颜色越深代表当天完成的事越多
- 统计卡：连续打卡天数、本月完成任务、打卡率、日记篇数
- 情绪曲线、目标进度
- **周复盘 / 月复盘**：点按钮 → "✨ 生成草稿"（自动汇总本周数据成模板）→ 补写感想 → 保存

### 👤 档案（你的复利证明）
- 作品墙 / 里程碑 / 证书，带日期和链接
- 技能雷达图（至少加 3 个技能才会出现）
- "📇 生成自我介绍"：一键生成一段可以复制的介绍文案

### 🗄️ 数据（数据安全控制台）
- **立即备份**：手动做一次快照（其实每次启动也会自动备份，保留最近 30 份）
- **导出 ZIP / 导出 JSON**：把全部数据打包下载，建议每月存一份到 U 盘或网盘
- **回收站**：所有删除的内容都在这里，可恢复，"彻底删除"才是真删
- **习惯管理**：添加/删除要养成的习惯
- ⚠️ **恢复备份后需要关闭程序窗口，重新双击「启动.bat」**

**全局搜索**：任何时候按 `Ctrl + K`（或按 `/` 键），一次搜任务、日记、随手记、知识、成果。

## 三、你的数据在哪里？怎么保护？

所有数据都存在一个文件夹里：

```
life-compound\backend\data\
├── life.db          ← 全部数据（SQLite 数据库）
├── backups\         ← 自动 + 手动备份
└── uploads\         ← 上传的图片
```

**三重保护已经内置**：
1. 每次启动自动备份（保留 30 份）
2. 恢复备份前会自动再做一次"恢复前快照"——手滑也有后悔药
3. 删除任何内容先进回收站

**建议养成习惯**：每月去「数据中心 → 导出 ZIP」存一份到 U 盘/网盘。
（JSON 导出是纯文本格式，万一数据库文件损坏，数据也能捞回来。）

**换新电脑**：把整个 `life-compound` 文件夹拷过去，新电脑装好 Python 后运行一次
`首次安装.bat` 即可（数据都在文件夹里，跟着走）。

## 四、开机提醒

注册后，开机如果今天还没写任务，Windows 右下角会弹通知提醒你。

- 开启：运行 `首次安装.bat` 时按 Y；或直接双击 `scripts\register_reminder.ps1`（右键 → 使用 PowerShell 运行）
- 关闭：在 PowerShell 里运行
  `powershell -File "scripts\register_reminder.ps1" -Remove`

## 五、常见问题

| 问题 | 解决办法 |
|---|---|
| 双击启动后窗口一闪而过 | 先运行 `首次安装.bat`；还不行就检查 Python 是否装好（命令行输入 `python --version` 试试） |
| 页面打不开 / 一直等待 | 可能 8910 端口被其他软件占用。关掉旧窗口重试；或修改 `启动.bat` 和 `backend\app\main.py` 里的端口号（两处都要改） |
| 依赖安装很慢/失败 | 检查网络；脚本已用清华镜像，公司内网可能需要代理 |
| 误删了重要内容 | 去「数据中心 → 回收站」恢复 |
| 数据库损坏打不开 | 用「数据中心」之前导出的 ZIP / JSON 恢复；或从 `backend\data\backups\` 里挑一份最近的备份文件恢复 |
| 想改程序/加功能 | 见下方"开发者说明" |

## 六、开发者说明（想改代码时看）

```
life-compound\
├── 启动.bat / 首次安装.bat     ← 用户入口（GBK 编码，勿用记事本改存为 UTF-8）
├── prototype\index.html        ← 最早的视觉原型（静态演示，可删）
├── backend\                    ← Python 本地服务
│   ├── app\main.py             ← 入口：路由注册、静态托管、安全中间件
│   ├── app\db.py               ← 数据库建表、连接、版本迁移
│   ├── app\backup.py           ← 备份/恢复/导出
│   ├── app\security.py         ← 只允许本机访问的校验
│   ├── app\crud.py             ← 通用增删改查工具
│   ├── app\routers\            ← 各模块 API（tasks/habits/goals/...）
│   └── data\                   ← 你的数据都在这（勿删）
├── frontend\                   ← React + TypeScript 界面
│   ├── src\theme.css           ← 设计系统（改配色/圆角就在这）
│   ├── src\pages\              ← 七个页面的代码
│   └── dist\                   ← 构建产物（正式运行用的就是它）
└── scripts\                    ← 启动/提醒/测试辅助脚本
```

**改了界面代码后要重新构建**（需要装过 Node.js）：

```bash
cd frontend
npm install        # 第一次才需要
npm run build      # 重新构建，几十秒
```

构建完重新双击 `启动.bat` 就是新界面。

**改了后端代码**：关掉窗口重新双击 `启动.bat` 即可（无需构建）。

**跑后端自动化测试**：`python scripts\test_api.py`（37 项全过即正常）。
