# 🎨 打造你自己的 IP 吉祥物

把你的真人照片变成会打招呼、会比心的卡通形象，放进这个系统。
全程用 AI 完成，不需要美术基础。整个流程分 **生成 → 抠像 → 动画 → 放置** 四步。

> 你将得到：一张静态形象图 + 一段透明背景循环动画 + 挥手/比心两个互动手势

---

## 第 1 步：生成角色设定稿（豆包 / 即梦等 AI 生图）

上传一张你的清晰正面照片，配合下面的提示词（特征部分换成你自己的）：

```text
根据我上传的照片，设计一个属于我的专属卡通IP形象：
- 身份特征：黑色长直发过胸、中分八字刘海、发尾微卷；圆润鹅蛋脸、白皙肤色、
  大杏眼双眼皮、笑起来眼睛弯成月牙、嘴角上扬；头顶架一副黑色墨镜、
  银色圆圈耳环；穿米白色高领毛衣，衣服上有一个草莓粉小蝴蝶结挂件
- 风格：治愈系Q版手绘，头身比约1:2.5，线条圆润，大眼睛带高光，
  低饱和奶油色系配色，温柔软糯气质
- 呈现：同一个角色的三视图（正面、侧面、背面），全身站立，
  三视图的发型、服装、配饰、比例完全一致
- 背景：纯白色，无文字、无水印、无边框，角色设定稿
```

**关键**：特征逐项写全（发型/服装/配饰/比例），这是后面所有图保持"同一张脸"的锚。

## 第 2 步：生成展示视频（豆包 / 即梦视频功能）

用设定稿 + 提示词生成 10~15 秒视频：

```text
请依照提供的人物形象，生成视频：角色正面全身站立，纯色绿幕背景（便于抠像），
柔和摄影棚灯光。动作：缓慢转身展示一圈 → 回到正面微笑站立 → 双手比心 →
抬手挥手打招呼。全程无文字、无水印、无其他人物。
```

**避坑**：
- 背景要是**纯色**（绿或灰绿都行，程序能处理）；人物身上别带绿色元素
- 视频里"转身段"后面会被剪掉——只保留正面小动作和手势段
- 现在主流模型写透明通道还有 bug，所以先生成绿幕视频再抠，别直接要透明

## 第 3 步：抠像 + 做动画（本仓库自带脚本）

把视频放到 `assets/ip/` 下，然后：

```bash
cd assets/ip

# 1. 待机循环（正面小动作）——改 make_animation.py 顶部 CLIP_RANGES 选段
python make_animation.py
#    产出 mascot_anim.webm（透明循环）+ ip_v2_static.png（静态图）

# 2. 手势段（挥手/比心）——改 extract_gestures.py 顶部 GESTURES 帧号
python extract_gestures.py
#    产出 gesture_wave.webm / gesture_heart.webm
```

脚本原理（改参数前了解一下）：
- `process_ip.py`：floodFill（FIXED_RANGE 模式）从画面四边按色差吃掉背景 → despill 去绿边
- `make_animation.py`：抽帧（隔 2 取 1 = 12fps）→ 抠像 → 统一画布对齐 → 透明 WebM
- 帧缓存存在 `anim_frames_v3/`，调编码参数时不用重新抠像

没有 Python 环境的替代方案：**剪映 → 色度抠图** 手动抠，导出带透明通道的
WebM/序列帧，效果一样，只是费手。

## 第 4 步：放进系统

把 4 个文件放到 `frontend/public/mascot/`（目录不存在就新建）：

| 文件 | 说明 |
|---|---|
| `mascot.png` | 静态形象（透明背景 PNG，建议高度 ≥600px） |
| `idle.webm` | 待机循环动画（透明） |
| `wave.webm` | 挥手动画（透明，1~3 秒） |
| `heart.webm` | 比心动画（透明，1~3 秒） |

然后重新构建：

```bash
cd frontend && npm run build
```

刷新页面——今日页、欢迎页、档案页的吉祥物全部换成你的了，还带着
悬停打招呼、点击比心的互动。没有放动画文件时系统会自动降级为静态图，
只放 `mascot.png` 一张图系统也能跑。

## 隐私说明

`frontend/public/mascot/`（你的形象）和 `backend/data/`（你的数据）都在
`.gitignore` 里——**开源上传时不会带上你的脸和你的记录**。仓库里只有
处理脚本和这份教程，别人照着做自己的。
