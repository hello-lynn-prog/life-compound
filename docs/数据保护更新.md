# 数据保护更新

本次只修改数据保护相关部分，正式数据库未被测试写入。源文件修改前备份在 change-backups 下。

- ZIP 导出使用 SQLite 一致性快照，包含 WAL 中的数据。
- ZIP 导入先解压到临时目录、检查路径及数据库完整性，再备份当前库并恢复。
- JSON 导出包含重复任务规则及 schema 版本。
- 自动备份按修改时间淘汰旧文件。
- 修复 31 日生成月复盘的日期错误。
- 日记和任务总结停止输入约 1.2 秒后自动写入数据库，显示保存状态。
- 输入时同步保存浏览器草稿；未写入数据库的内容，重新打开相同编辑入口可恢复。
- 随手记请求成功后才清空，失败保留输入。浏览器草稿依赖相同浏览器及访问地址。

建议更新后重新启动本地服务，并在浏览器 Ctrl+F5 刷新。数据库及附件仍需定期导出到另一个磁盘。此次未实现跨标签页冲突解决，也没有替代异地备份。

验证：前端 TypeScript 和生产构建；隔离临时数据库的 WAL 导出、ZIP 恢复往返、JSON 重复规则导出、危险 ZIP 路径拒绝测试。浏览器端编辑交互尚待实测。
